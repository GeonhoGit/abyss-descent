# 심연 강하 그래픽 방향

- 사용자 선택: 묵직한 석조 던전과 횃불이 중심인 다크 판타지.
- 목표: 던전 재질, 적의 실루엣, 장비, 메뉴와 HUD를 일관된 분위기로 바꾼다.
- 구현 판단: 기존 단일 HTML·Canvas 레이캐스팅·64×64 절차적 텍스처를 유지한다. 게임 실행에는 추가 패키지나 네트워크가 필요하지 않다.
- 대안: 외부 이미지 기반 교체는 자산 로딩을 추가하고, 3D 엔진 교체는 전투·맵 구현까지 변경하므로 이번 범위에서 제외했다.
- 색: 먹빛 `#0b1518`, 청록 석재 `#1a2b2c`, 낡은 황동 `#b59b67`, 불씨 `#e5a662`, 뼈 `#d2c6ab`, 영혼 `#78b9b0`.
- 글자: 메뉴 제목은 로컬 바탕/Georgia 세리프, 본문과 HUD는 기존 한글 sans-serif. 외부 폰트를 추가하지 않는다.
- 던전: 돌의 균열·모서리 음영·바닥 틈·쇠 횃불 받침·층별 거리 안개. 질감 생성은 초기화 시 한 번만 수행한다.
- 적과 장비: 해진 옷, 갑옷과 금속의 밝은 모서리, 작고 밝은 안광. 어두운 배경에서도 적을 구분할 수 있어야 한다.
- 화면 구성: 좌측 타이틀 패널, 황동 테두리 메뉴, 하단 양끝 HUD, 우상단 소형 지도. 모든 기존 정보와 제어 ID를 유지한다.
- 변경하지 않는 범위: 전투 수치, 맵 생성, 입력 규칙, 저장 형식과 기존 버그 수정.
- 확인: 기존 13개 회귀 검사, 화질 3단계·무기 6종 렌더 실행, 같은 테스트 장면의 전후 이미지, HTML 구조 점검.
- 제한: 브라우저 로컬 파일 접근이 차단되어 Canvas는 Node에서 실제 래스터화하고 메뉴는 정적으로 확인한다. 미리보기는 테스트 장면이며 브라우저 플레이 캡처가 아니다.
