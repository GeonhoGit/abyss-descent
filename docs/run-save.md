# 원정 저장 계약

- 영구 강화/영혼은 기존 `abyss_save_v2`, 진행 중인 원정은 별도 `abyss_run_v1`에 저장한다.
- 스냅샷 버전은 1이다. 플레이어·무기·능력·탄약·마나, 맵·탐색 영역·조명·방, 적과 보스 참조, 날아가는 투사체, 아이템·포탈, 층 진행도, 대기 중인 레벨업 선택과 상점 재고를 보존한다.
- 투사체 이미지는 `SP` 카탈로그 ID로 저장하고 복원 시 실제 텍스처에 다시 연결한다. 상점 상품 이름·설명·효과 함수는 `kind/art` 카탈로그에서 재구성한다. 일회성 파편·피해 숫자 같은 시각 효과는 복원 시 비운다.
- 실제 전투 진행 5초마다, 정보창을 열 때, 능력/상점 화면 갱신, 능력 선택, 상점 닫기, 층 전환, 창 포커스 상실/숨김/종료, 저장 후 나가기에서 체크포인트를 만든다.
- `saveRun()`은 저장 성공 여부를 반환한다. `suspendRun()`은 성공했을 때만 타이틀로 나간다. 저장 실패 시 이전 저장을 성공했다고 표시하지 않으며 현재 원정은 유지된다.
- 종료 영혼 정산도 영구 데이터 저장에 성공해야 원정 체크포인트를 삭제한다. 실패 시 메모리의 미확정 영혼·기록을 되돌리고 체크포인트를 보존하여 이전 원정을 이어할 수 있게 한다.
- 새 원정 시작은 이전 체크포인트를 대체한다. 포기/사망의 `endRun()`은 영혼 정산 후 체크포인트를 삭제하고 영구 데이터에 종료된 원정 ID를 기록하여 같은 원정의 재복원을 차단한다. 승리 화면은 무한 모드 진입 전까지 이어할 수 있다.
- 복원 전 버전, JSON 크기, 유한 수치, 플레이어 생존/위치, 지도 크기와 경계, 카탈로그 ID, 능력 단계, 보스 연결과 대기 화면 상태를 검사한다. 실패 시 현재 게임 상태와 영구 데이터는 변경하지 않는다.
- 미리보기 생성기는 `RUN_SAVE_ENABLED=false`로 원정 저장의 읽기·쓰기를 모두 끈다. 실제 게임과 미리보기는 저장 기록을 공유하지 않는다.

검증: `node --test tests/run-save.test.cjs`. 독립 게임 세션 간 복원, 실제 보스 드롭, 상점 구매 효과와 품절 유지, 대기 선택/승리 화면, 손상 데이터 거부, 종료 보상 중복 방지, 저장 실패와 자동 저장을 확인한다.
